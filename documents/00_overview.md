# 今日これだけメーカー 設計概要

## 目的

「今日やること」は複数あるが、どれから始めるか決められず行動が止まってしまう人に向けて、最初の一歩を決めるWebアプリを作る。

本アプリは厳密なタスク管理ではなく、迷いを減らして行動開始を助けることを目的とする。ログイン、保存、履歴、通知などは持たず、画面上のstateだけで完結する。

## アプリ名

今日これだけメーカー

## 想定ユーザー

- 今日やることが多すぎて動けない人
- 優先順位を考えるのが面倒な人
- Todoリストを作って満足してしまう人
- とりあえず1つだけでも行動したい人
- 勉強、仕事、副業、家事などのタスクを整理したい人

## 開発前提

- 1日1アプリとして開発する
- フロントエンド中心のWebアプリ
- ログイン機能は実装しない
- データベースは使わない
- 入力内容はReact stateで管理する
- リロード時にデータは消えてよい
- スマホでも使いやすいレスポンシブUIにする
- Vercelへのデプロイを前提にする

## 使用技術

- Next.js
- React
- TypeScript
- Tailwind CSS

## MVP範囲

- モード選択
- タスク追加
- タスク削除
- 今日これだけモード
- 適当優先順位モード
- 重要度バイアス抽選モード
- 結果表示
- レスポンシブ対応

## 実装しないこと

- ログイン機能
- データベース保存
- 通知機能
- カレンダー連携
- AIによる本格的な優先順位判定
- ユーザーごとの履歴管理
- 複雑なカテゴリ管理

## 体験方針

ユーザーに「完璧に優先順位を決めなくてもよい」「今日これだけやればOK」と感じてもらう。タスク管理アプリらしい堅さよりも、軽さ、遊び心、背中を押す雰囲気を優先する。

## 成功条件

- ユーザーが2件以上のタスクを入力できる
- 3つのモードから結果を作成できる
- 結果画面で次にやることが明確にわかる
- 重要度バイアス抽選では重要度が高いタスクほど選ばれやすい
- スマホ幅でも入力、削除、実行がしやすい
