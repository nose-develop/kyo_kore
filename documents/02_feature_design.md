# 機能設計

## データ型

```ts
export type Task = {
  id: string;
  title: string;
  priority?: number;
};

export type Mode = "single" | "shuffle" | "weighted";
```

## 共通状態

- `tasks`: 入力済みタスク配列
- `mode`: 選択中のモード
- `result`: 実行結果
- `errorMessage`: バリデーションエラー
- `isDrawing`: 抽選中演出の表示状態
- `rerollCount`: 再抽選回数

## タスク入力機能

### 入力項目

通常モード:

- タスク名

重要度バイアス抽選モード:

- タスク名
- 重要度: 1から10

### 仕様

- タスクは最低2件以上入力した状態で実行できる
- 空欄のタスクは追加できない
- タスクは削除できる
- タスクは追加後に一覧表示する
- Enterキーで追加できる
- 重要度モードでは重要度未入力、範囲外をエラーにする

### バリデーション

| 条件 | エラーメッセージ |
| --- | --- |
| タスクが0件 | まずは今日やることを入力してください。 |
| タスクが1件 | 2つ以上入力すると、優先度を決められます。 |
| タスク名が空欄 | タスク名を入力してください。 |
| 重要度が未入力 | 重要度を1〜10で入力してください。 |
| 重要度が範囲外 | 重要度は1〜10で入力してください。 |

## 今日これだけモード

### 概要

入力されたタスクの中からランダムで1つだけ選び、「今日はこれだけやればOK」と表示する。

### ロジック

1. タスク数が2件以上か検証する
2. `Math.random()` で0からタスク数未満のindexを作る
3. 対象タスクを結果として保存する

### 表示

- 選ばれたタスクを大きく中央表示する
- 「他はできなくてもOKです。まずはこれだけやりましょう。」のような励ましを表示する
- 再抽選ボタンを表示する

### 再抽選注意文

再抽選回数が1回以上なら以下を表示する。

```text
選び直してもOKですが、迷いすぎ注意です。3回以内に決めましょう。
```

## 適当優先順位モード

### 概要

入力されたタスクをランダムに並び替え、1位から順番に表示する。正確な優先順位ではなく、考える負担を減らすための順番決めとする。

### ロジック

1. タスク数が2件以上か検証する
2. Fisher-Yates shuffleなどでタスク配列をランダムに並び替える
3. シャッフル後の配列を結果として保存する

### 表示

- 「今日のおすすめ順番」をタイトルにする
- 1位から順番に番号付きで表示する
- 「この順番でやる」感が出るよう、1位を少し強調する
- 再作成ボタンを表示する

## 重要度バイアス抽選モード

### 概要

各タスクの重要度を重みとして扱い、重要度が高いタスクほど選ばれやすいランダム抽選を行う。最大値を必ず選ぶのではなく、重要度に比例した確率で選ぶ。

### ロジック

1. タスク数が2件以上か検証する
2. 全タスクに1から10の重要度があるか検証する
3. 重要度の合計値を計算する
4. `0 <= random < totalWeight` の乱数を作る
5. タスクの重要度を累積し、乱数が累積値以下になったタスクを選ぶ

### 確率例

| タスク | 重要度 | 確率 |
| --- | ---: | ---: |
| A | 3 | 3/20 |
| B | 7 | 7/20 |
| C | 10 | 10/20 |

### 表示

- 選ばれたタスクを大きく中央表示する
- 「重要度を考慮した結果、今日はこれをやりましょう。」と表示する
- 選択理由を短く表示する

### 選択理由文言例

- 重要度が高いため、今日取り組むタスクとして選ばれました。
- 重要度を重みとして抽選した結果、このタスクが選ばれました。

## 抽選中演出

余裕がある場合、実行ボタン押下後すぐに結果を出さず、約1秒の抽選中状態を表示する。

### 文言候補

- 考え中...
- 今日の運命を決定中...
- 迷いを断ち切っています...

### 挙動

1. 実行時に `isDrawing` を `true` にする
2. 抽選中文言を表示する
3. 約1000ms後に結果を表示する
4. `isDrawing` を `false` にする

## 励ましメッセージ

結果表示時にランダムで1つ表示する。

候補:

- 今日はこれだけできれば勝ちです。
- まずは5分だけ始めましょう。
- 完璧じゃなくてOKです。
- 迷う時間を行動に変えましょう。
- 終わったら自分を褒めてください。
